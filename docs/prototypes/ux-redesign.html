扩展点标注

原型工具，不是产品界面。目标态与插件内可做到的范围分开写；红色项需要宿主增强。

结论：任务视图、任务详情、通知浮层/抽屉、文件页、设置里的运维页都能落在现有插件槽位；主 Agent 大卡置顶、移除宿主「新会话」和会话/工作区列表、把设置弹窗完全改成原型样式需要宿主增强或替换 sidebar 包。
界面 / 元素扩展点可行性说明
全局 / 主菜单
主 Agent「小助」入口sidebar.panellist + main部分可作为第一条面板行、自定义头像图标；点开可跳转主 Session。大卡、副标题、状态点、立在「新会话」上方不可得。
任务 / 通知 / 文件sidebar.panellist ×3 + main keyed panels插件内每个 id 对应一个 main 面板；order 控制插件行顺序。宿主「插件」行与工作区区域仍在。
未读数字 / 红点面板图标 SVG 内绘制插件内可行；但行本身没有 badge 属性，数字要画在 16px 图标里，或用一个小圆点。
底部「设置」sidebar.settings（宿主）沿用触发行与设置外壳归 ui-settings；插件不替换。
移除「新会话」、插件行、工作区/会话列表宿主 sidebar 组合；sidebar.workspaces（ui-workspace 独占）需宿主「新会话」/「插件」由宿主组合固定；workspace/会话列表由 ui-workspace 独占。插件不能移除、过滤或重排。
主 Agent
对话、任务卡、提问卡主 Session + 现有任务卡/relay；入口 conversation.hero.options；状态页 conversation.view插件内对话是宿主 Session；任务卡复用现有 relay/Goal 投影，入口由插件注册。
改名 / 换头像session/registration label + 面板 icon部分会话显示名可改；头像在面板 icon 内可换，主菜单大卡头像不可控。
置顶 / 主徽标pinSession + sidebar.session.row.leading插件内只能影响宿主会话行；不能把它变成主菜单第一项。
任务视图 / 详情
任务视图（含目标分组）main keyed panel插件内整页由插件渲染；根 Ticket / 子 Ticket 读现有投影，不需要新表。
任务关系层级读模型：parentTicketId / rootTicketId插件内关系是现有 Ticket 字段；UI 只画树，不新增授权。
负责人 profileAgentProfile / 负责人投影阶段依赖Phase 1 子任务沿用根任务 profile；不同子任务不同 profile 见 docs/016 Phase 2。
任务会话 / 交付 / 阻断 / 汇报Assignment、Deliverable、Report、person stage 投影插件内会话入口到 E3；默认面只显示数量与负责人，不显示 Session id。
通知
右侧浮层通知shell.overlay（list）插件内frame 级浮层，click-through，子项自己接管 pointer events；可做栈、间距、自动收起。
通知抽屉 / 全部shell.overlay + 插件状态插件内抽屉是插件自己的浮层；未读游标可存本地，跨设备同步需服务端。
主菜单「通知」一级入口sidebar.panellist 面板行部分可以有插件面板行；不是宿主原生 nav，不能替换宿主通知中心。
文件 / 设置
文件页main keyed panel + 插件文件读模型插件内交付物按任务归档；执行目录只在高级详情。宿主自己的文件侧栏仍在，不重复目录树。
设置弹窗 / 导航sidebar.settings 外壳 + settings.section部分可新增「系统与运维」独立页；不能整体替换设置弹窗、不能删宿主已有分区。
系统与运维页settings.section插件内来源健康、触发、队列、审计、部署、策略都收进这一页；E2/E3。
取消独立运维页插件自身路由插件内从默认面板移除旧 7 tab；深链从通知进入具体项，不打开整个运维台。
